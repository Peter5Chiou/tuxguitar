# SimpleInput — TuxGuitar 刷法譜匯入 plugin

用簡單文字格式（`.strum`）寫吉他刷法譜，透過 TuxGuitar 的 **File → Import → SimpleInput Strum** 匯入，
直接在 TuxGuitar 顯示五線譜/六線譜、和弦圖、刷弦方向，並可播放與編輯。

## 檔案格式（.strum）

```
% 註解（% 到行尾）

M:4/4        % 必要，拍號（分母定義一拍的時值）
L:1/8        % 必要，基礎時值單位
Q:1/4=90     % 可選，速度 BPM（以四分音符記）
K:C          % 可選，調性
T:+5         % 可選，整首上移 5 個半音（也可寫 T:5 或 T:-2）

@basic  = d2u2d2u2              % 定義可重用刷法（不可巢狀引用）
@arp    = t (23) 1 (23) 1 (23) 1 (23)

G(4) @basic | C(4) @island | Am(4) @arp | F(4) @basic C(4) @basic ||
```

### 標頭

| 標頭 | 必要 | 說明 |
|---|---|---|
| `M:` | ✓ | 拍號。**分母定義一拍**：4/4 = 四分音符一拍；6/8 = 八分音符一拍 |
| `L:` | ✓ | 基礎時值單位。4/4 + `L:1/8` → 1 基礎單位 = 半拍（每拍 2 單位） |
| `Q:` | | 速度，`Q:1/4=90` = 四分音符 90 BPM。省略時預設 90 |
| `K:` | | 調性（目前僅記錄，不影響輸出） |
| `T:` | | 整首移調半音數；正數上移、負數下移，`T:+5` 等同 `T:5` |

`T:` 會移調所有和弦名稱與實際音高。和弦優先使用移調後和弦的字典指法（因此可保留開放和弦）；字典沒有該和弦指法時，會移調原指型，必要時重新配置弦位或使用八度等音。`@N` 保留原本的寫法，套用在移調後的和弦指法上。和弦後未強制品位的單弦／多弦拾音會依移調後的和弦指法取音；`弦=品` 則將指定品位按 `T` 加減，並留在指定弦上，超出 0～24 品時會報錯。沒有和弦時，未強制的單弦音以空弦音高加上 `T` 移調。

### 時值規則

- **和弦後括號數字 N ＝ N 拍**（以 `M:` 分母為一拍）。`G(4)` = G 和弦 4 拍；`Em9(4)` = Em9 和弦 4 拍。和弦名稱中的數字不代表拍數。
- **事件後數字 ＝ 基礎單位數**。`d2` = 下刷 2 個基礎單位。
- pattern 事件的總基礎單位數**必須剛好等於**和弦拍數換算的單位數：
	- 4/4 + `L:1/8`（每拍 2 單位）：`G(4) d2u2d2u2` = 4拍×2 = 8 單位 ✓
  - `G(4) dudu` = 只有 4 單位 ≠ 8 → **錯誤**（錯誤訊息會指出行號與小節）
- 和弦後沒括號拍數：持續時間由 pattern 總長決定（`G d2u2d2u2` = 8 單位）。
- 和弦後沒 pattern：需要使用括號指定拍數，例如 `G(4)` 代表一次下刷全和弦，持續 4 拍。
- **弱起**：第一小節可不足拍，但弱起 + 末小節合計必須等於整小節單位數。
- 指定把位:
    和弦名稱@把位(拍數)，例如:
    Em@3(4)      % Em 按型從第3品開始，持續4拍
    Em@7(2)      % Em 按型從第7品開始，持續2拍
    指定把位會將該和弦按型的所有非悶弦品位整體平移；把位範圍為 1~24。

### 反覆（`|: ... :|`）

用 `|:` 與 `:|` 包住要反覆的小節。`:|` 後可接數字 N，表示**總共演奏 N 次**（不是額外再彈 N 次）：

| 寫法 | 意思 |
|---|---|
| `|: ... :|` | 總共演奏 2 次（反覆 1 次） |
| `|: ... :|2` | 同上，總共 2 次 |
| `|: ... :|3` | 總共演奏 3 次 |
| `|: ... :|4` | 總共演奏 4 次 |

- 數字緊接在 `:|` 後面，中間可有空白：`:|3` 或 `:| 3` 都接受。
- 沒寫數字時，預設當作 `:|2`（總共 2 次）。
- `|:` 與 `:|` 可以跨多行：反覆區段可橫跨任意多行，只要 `|:` 在第一個小節前、`:|` 在最後一個小節後即可。
- `:|` 前若有多餘的小節線（如 `G @G| :|`）也可接受，會套用到前一個小節。
- 目前只支援單一層反覆（不處理巢狀反覆、`1.` `2.` 結尾等複雜情況）。
- 注意：TuxGuitar 內部以「額外反覆次數」儲存，因此 `:|3` 在譜面上會顯示為 `x2`（總次數 3 = 額外 2 次），但播放次數正確。

範例：

```
% 這段總共彈 2 次
|: G(4) @basic | C(4) @basic :|

% 同上（明確寫 2）
|: G(4) @basic | C(4) @basic :|2

% 這段總共彈 3 次
|: G(4) @basic | C(4) @basic | Am(4) @basic | F(4) @basic :|3
```

### 事件符號

| 符號 | 意思 |
|---|---|
| `d` | 下刷。未指定弦＝刷和弦發音弦（若刷法包含 `t` 彈根音，自動排除根音弦）；`d:45` 只刷 4、5 弦 |
| `u` | 上刷，同上 |
| `t` | 彈和弦根音（單音） |
| `x` | 短刷：根音 + 根音旁靠高音側一根弦（根音第 5 弦 → 刷 5、4 弦） |
| `1`~`6` | 彈單一弦；和弦圖的 `x` 不限制指法，未指定品位時使用空弦 |
| `(23)` | 同時彈 2、3 弦；和弦圖的 `x` 不限制指法。可接 `*N`/`/N` 調整時值，如 `(6321)*2`；括號內數字可用空格分隔，如 `(6 3 2 1)*2`。括號內每根弦可指定品位，如 `(6 3=4 2=5 1=3)*2`（弦 3 按 4 品、弦 2 按 5 品、弦 1 按 3 品，弦 6 用和弦原品位） |
| `2=3` | 強制品位：第 2 弦強制按第 3 品（覆寫和弦原按法） |
| `@seq1`~`@seq8` | Ample Guitar 內建音序器刷法（免檔頭定義，自動填滿和弦拍數） |
| `z` 或 `-` | 休止 |

數字可接在 `d`/`u` 後：`d2` = 下刷 2 單位；指定弦用冒號：`d2:45` = 下刷 2 單位只刷 4、5 弦。刷法指定到和弦圖的 `x` 弦時，會輸出悶音。

事件後可用 `*N` 或 `/N` 調整時值：`2` = 第 2 弦基本時值、`2*2` = 時值乘 2、`2/2` = 時值除 2、`d/2` = 下刷半個基本單位。短刷支援 `x2` 與 `x*2`。
強制品位使用等號，品位在時值之前，例如 `2=3*2` = 第 2 弦按第 3 品，時值乘 2。

### 連音群組（`[..]`）

用方括號 `[..]` 包住多個事件，這些事件**平均分在 1 拍**（以 `M:` 分母為一拍）：

| 寫法 | 意思 |
|---|---|
| `[t 1 2]` | 三連音指法（3 個事件分 1 拍） |
| `[x x x]` | 三連音短刷 |
| `[d u d u d u]` | 六連音刷法（6 個事件分 1 拍） |

群組內事件數**必須是 3、5 或 6**（對應 TuxGuitar 支援的三/五/六連音），否則報錯。群組內事件可用空格分隔，事件語法與一般事件相同（`d`/`u`/`x`/`t`/數字/`(..)`/`z` 等）。

### 刷速指定（`~N`）

`d`/`u`/`x` 後可用 `~N` 指定刷速（N = 4~64 分音符）：

| 寫法 | 意思 |
|---|---|
| `d2:123~16` | 下刷，時值×2，指定 123 弦，刷速 16 分音符 |
| `u:321~8` | 上刷，指定 321 弦，刷速 8 分音符 |
| `x2~64` | 短刷，時值×2，刷速 64 分音符 |
| `d~32` | 下刷全弦，刷速 32 分音符 |

**刷速繼承**：未指定 `~N` 時預設為 **16 分音符**。一旦指定 `~N`，後續所有未指定的刷法（`d`/`u`/`x`）都會沿用該刷速，直到再次指定新的 `~N`。例如：

```
d~32 u d u      % 後面的 u、d、u 都是 32 分音符
d~32 u d~16 u   % 最後面的 u 是 16 分音符（d~16 之後）
```

`~N` 只影響刷弦的 TGStroke 速度標示，不影響事件本身的時值。N 必須是 4 到 64 之間的 2 的冪（4、8、16、32、64），否則報錯。

### 力度指定（`!ppp` ~ `!fff`）

`d`/`u`/`x`/`t`/單弦/多弦等事件**尾端**可用 `!` 接力度標記（放在事件最後，`~N` 之後）：

| 寫法 | 意思 |
|---|---|
| `d2:45~16!f` | 下刷，時值×2、刷 45 弦、刷速 16 分音符，力度 **f** |
| `u:321~8!p` | 上刷，刷 321 弦、刷速 8 分音符，力度 **p** |
| `x2~64!mp` | 短刷，時值×2、刷速 64 分音符，力度 **mp** |
| `d2!f` | 下刷，時值×2，力度 **f** |
| `t!ppp` | 彈根音，力度 **ppp** |
| `(23)!mf` | 同時彈 2、3 弦，力度 **mf** |
| `[d!f u!p d!f]` | 三連音內每個事件可各自指定力度 |

支援 8 段力度：`ppp`、`pp`、`p`、`mp`、`mf`、`f`、`ff`、`fff`（對應 TuxGuitar 的力度值）。力度只套用該事件本身，**不繼承**；未指定 `!力度` 的事件維持 TuxGuitar 預設力度（f）。不支援的標記（如 `!x`）會報錯。

### Ample Guitar 內建音序器刷法（`@seq1` ~ `@seq8`）

可以直接在和弦後指定 Ample Guitar Strummer 內建的 Pattern 音序器刷法：

| 寫法 | 意思 |
|---|---|
| `G(4) @seq1` | G 和弦持續 4 拍，自動調用 Ample Guitar 內建 Pattern SEQ 1 |
| `C(4) @seq2` | C 和弦持續 4 拍，調用 Pattern SEQ 2 |
| `Em(2) @seq1 D(2) @seq3` | 同一小節內不同和弦各自調用不同 SEQ Pattern |
| `G(4) @seq1!ff` | 可接 `!` 指定力度 |

- **免手動定義**：不需要在檔頭宣告 `@seq1 = ...`，Parser 自動識別為保留關鍵字。
- **自動撐滿拍數**：自動根據和弦括號內的拍數換算時值（如 `G(4)` 自動佔滿 4 拍），不需手動湊齊八分音符單位數。
- **MIDI 對應**：匯出至 MIDI 時，會自動輸出對應的 SEQ Keyswitch（`@seq1`=Note 60, `@seq2`=Note 61, `@seq3`=Note 63, `@seq4`=Note 66, `@seq5`=Note 68, `@seq6`=Note 70, `@seq7`=Note 73, `@seq8`=Note 75），在該和弦期間驅動 Ample Guitar 自動演奏內建節奏。TuxGuitar 匯入時則以全刷呈現。

### 弦編號（特殊習慣）

只有 **1 和 3 對調**，其餘與物理弦號相同：

| 檔案寫 | 實際弦 |
|---|---|
| 1 | 3 |
| 2 | 2 |
| 3 | 1（最細，高音 e） |
| 4 | 4 |
| 5 | 5 |
| 6 | 6（最粗） |

### 和弦

內建開放和弦：C D E Em Am A A7 D7 E7 G G7 F Cadd9 Dm Asus4 Dsus4 B7 Bm7 Em7。
未內建的和弦自動以**封閉和弦推導**（E 形/A 形，取把位較低者），支援 major/minor/7/m7 與升降半音（F#m、Bb、C#m、F#m7…）。
未識別的和弦名 → 匯入錯誤。

### 錯誤報告

錯誤格式為 `第 N 行、第 M 小節：描述`，任何錯誤會中止匯入。

## 安裝

`mvn package` 產生的 `tuxguitar-simpleinput.jar` 已自動組裝進發行版的 `share/plugins/`。
手動安裝：把 jar 複製到 TuxGuitar 發行版的 `share/plugins/`（或使用者外掛目錄），重啟 TuxGuitar。

## 使用

1. 啟動 TuxGuitar
2. **File → Import → SimpleInput Strum**
3. 選擇 `.strum` 檔

## Ample Guitar + Reaper 匯出 (AmpleGuitarExporter)

提供獨立 CLI 工具，讀取 `.strum` 檔案並輸出至 Reaper + Ample Guitar (Select Mode / Strummer) 專用的控制檔案：

```bash
# 編譯
javac -cp "common/TuxGuitar-simpleinput/target/classes;common/TuxGuitar-lib/target/classes" -d SimpleInput/tools SimpleInput/tools/AmpleGuitarExporter.java

# 執行匯出（output_dir 省略時預設輸出至 input.strum 同目錄）
java -cp "common/TuxGuitar-simpleinput/target/classes;common/TuxGuitar-lib/target/classes;SimpleInput/tools" AmpleGuitarExporter <input.strum> [output_dir]
```

### 輸出檔案

1. **`<檔名>.chords`（和弦庫 XML）**：
   - 自動掃描全曲用到的相異指型（支援把位指定與 `弦=品` 強制品位衍生 Slot），依序分配 ID="1" 到 ID="24"（最多支援 24 組，超出時報錯）。
   - 不足 24 個 Slot 時自動補滿預設 `C Maj`，悶弦標記為 `Fret="-1"`，供 Ample Guitar Select Mode 直接載入。
2. **`<檔名>_ag.mid`（Reaper 控制訊號標準 MIDI）**：
   - **標頭與反覆展開**：PPQ=480，寫入 Tempo、Time Signature、和弦變換 Marker；反覆記號 `|: ... :|N` 自動展開成線性時間軸。
   - **左手和弦槽位切換 (Note 36 ~ 59)**：對應 Slot 1~24（`Note = 35 + Slot_ID`），長音符持續至該和弦結束前 2 ticks；遇強制品位衍生 Slot 時短暫切換並切回。
   - **右手動作觸發**：
     - 一般全刷：下刷 `d` = **Note 72 (C4)**、上刷 `u` = **Note 76 (E4)**。
     - 單弦與根音撥弦：物理弦 6~1（粗→細）對應白鍵 **Note 62 (D3) ~ Note 71 (B3)**；`t` 自動查詢當前和弦根音物理弦送出單音。
     - 短刷 `x` 與指定弦刷法（如 `d:45`, `u:321`）：依下刷（粗→細）或上刷（細→粗）方向，帶微小 Tick 延遲依序送出單弦白鍵。
     - Ample 內建音序器：`@seq1`~`@seq8` 對應送出 Keyswitch 音符（C3=60, C#3=61, D#3=63, F#3=66, G#3=68, A#3=70, C#4=73, D#4=75）。
   - **刷速與 S-Strum Time**：刷弦事件自動發送 `CC #14`（~16 預設為乾脆的 10，~64=0, ~32=5, ~8=35, ~4=75）。
   - **力度**：`!ppp`~`!fff` 對應 MIDI Velocity 20~127（未指定預設 100）。

## 建置

```
cd G:\App\tuxguitar\desktop\build-scripts\tuxguitar-windows-swt-x86_64
mvn package -DskipTests
```

產出：`target\tuxguitar-9.99-SNAPSHOT-windows-swt-x86_64\`（含 `share\plugins\tuxguitar-simpleinput.jar`）。
注意：建置前需關閉執行中的 TuxGuitar，否則 jar 被鎖住會失敗。

## 開發環境

- JDK 24（`C:\Program Files\Java\jdk-24`）、Maven 3.9.16（`G:\App\apache-maven-3.9.16`）
- 原始碼：`common/TuxGuitar-simpleinput/src/app/tuxguitar/io/simpleinput/`
  - `SimpleInputParser.java` — Lexer/Parser/Validator（時值檢查、@展開、弱起）
  - `SimpleInputChordDictionary.java` — 和弦字典 + 封閉推導（低把位優先）
  - `SimpleInputSongBuilder.java` — IR → TGSong（TGBeat 用 preciseStart）
  - `SimpleInputReader.java` / `SimpleInputReaderPlugin.java` — TGSongReader 進入點
- 離線測試與工具：`SimpleInput/tools/`（`AmpleGuitarExporter.java`、`ParserTest.java`、`BuildTest.java`、`ReaderTest.java`）
- 規格細節：`SimpleInput/docs/SPEC.md`
