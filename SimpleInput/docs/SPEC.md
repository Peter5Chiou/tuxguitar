# SimpleInput (.strum) 規格 v1

> 狀態：依使用者 2026-09-08 回答定案。實作目標：TuxGuitar 匯入 plugin（`common/TuxGuitar-simpleinput/`）。

## 1. 檔案結構

```
% 註解（整行）
M:4/4        % 必要，拍號
L:1/8        % 必要，基本時值單位
Q:1/4=90     % 可選，速度（BPM）
K:C          % 可選，調性

@basic  = d2u2d2u2        % 定義區（可選），不允許巢狀引用
@arp    = t (23) 1 (23) 1

G(2) @basic | C(2) @island G(2) @basic | Am(4) @arp | F(2) @basic C(2) @basic ||
```

- 標頭：`M:`、`L:` 必要；`Q:`、`K:` 可選；順序不拘，只出現一次。
- `%` 到行尾為註解（行內註解也允許）。
- `@名稱 = 內容` 定義區只能出現在第一個小節線之前；譜面中 `@名稱` 引用。**不允許 @ 巢狀**（定義內引用另一個 @ 為錯誤）。
- 小節以 `|` 分隔；結尾 `||`（或 `|]`）。
- 弱起：第一小節可不足拍；最後一小節可補不滿；**弱起+末小節單位合計必須 = 拍號總單位數**，否則錯誤。
- 中間小節單位合計必須**剛好等於**拍號總單位數。

## 2. 事件符號

| 符號               | 意思                                      |
| ---------------- | --------------------------------------- |
| `d`              | 下刷（未指定弦＝刷目前和弦所有發音弦）                     |
| `u`              | 上刷（同上）                                  |
| `t`              | 彈和弦根音（單音）                               |
| `x`              | 短刷＝刷根音 + 根音旁靠高音側一根弦（如根音第 5 弦 → 刷 5、4 弦） |
| `1`~`6`          | 彈單一弦（編號見 §4 映射）                         |
| `(23)` / `(123)` | 同時彈多根弦                                  |
| `n=弦f`           | 強制品位（如 `2=3`＝第 2 弦強制按第 3 品，覆寫和弦原按法）     |
| `-` 或 `z`        | 休止                                      |

### 刷速指定（`~N`）

`d`/`u`/`x` 後可用 `~N` 指定刷速（N = 4~64 分音符）：

| 寫法 | 意思 |
| --- | --- |
| `d2:123~16` | 下刷，時值×2，指定 123 弦，刷速 16 分音符 |
| `u:321~8` | 上刷，指定 321 弦，刷速 8 分音符 |
| `x2~64` | 短刷，時值×2，刷速 64 分音符 |
| `d~32` | 下刷全弦，刷速 32 分音符 |

**刷速繼承**：未指定 `~N` 時預設為 **16 分音符**。一旦指定 `~N`，後續所有未指定的刷法（`d`/`u`/`x`）沿用該刷速，直到再次指定。例如 `d~32 u d u` 後面的 `u`、`d`、`u` 都是 32 分音符；`d~32 u d~16 u` 最後面的 `u` 是 16 分音符。

`~N` 只影響刷弦的 TGStroke 速度標示，不影響事件本身時值。N 必須是 4 到 64 之間的 2 的冪（4、8、16、32、64），否則報錯。

### 連音群組（`[..]`）

用方括號 `[..]` 包住多個事件，這些事件**平均分在 1 拍**（以 `M:` 分母為一拍）：

| 寫法 | 意思 |
| --- | --- |
| `[t 1 2]` | 三連音指法（3 個事件分 1 拍） |
| `[x x x]` | 三連音短刷 |
| `[d u d u d u]` | 六連音刷法（6 個事件分 1 拍） |

群組內事件數**必須是 3、5 或 6**（對應 TuxGuitar 支援的三/五/六連音），否則報錯。群組內事件可用空格分隔，事件語法與一般事件相同。

## 3. 時值與和弦語意

- 時值模型：
  
  - 「拍」由 `M:` 分母定義（4/4 = 四分音符一拍；6/8 = 八分音符一拍）。
  - 「基礎單位」由 `L:` 定義（4/4 時 `L:1/8` = 半拍 = 2 基礎單位/拍）。
    - **和弦後括號數字 N ＝ N 拍**（以 M: 分母為一拍）：`G(4)`＝4 拍；`Em9(4)`＝Em9 4 拍。和弦名稱中的數字不代表拍數；換算成基礎單位＝N ×（每拍基礎單位數）。
  - **事件數字 ＝ 基礎單位倍數**：`d2`＝2 個基礎單位；`dudu`＝4 個基礎單位。

- 事件可在基本時值後加 `*N` 或 `/N`：`2*2`＝時值乘 2，`2/2`＝時值除 2，`d/2`＝半個基礎單位；`x2` 與 `x*2` 都表示短刷時值乘 2。

- 強制品位使用 `=` 且品位在時值之前：`2=3*2`＝第 2 弦按第 3 品、時值乘 2。

- 指定把位:
    和弦名稱@把位(拍數)，例如:
    Em@3(4)      % Em 按型從第3品開始，持續4拍
    Em@7(2)      % Em 按型從第7品開始，持續2拍
  - 把位為 1~24，會將和弦按型所有非悶弦品位整體平移。
  

- **精確檢查（不自動縮放）**：和弦後的 pattern 事件總基礎單位數**必須剛好等於**和弦換算後的基礎單位數，否則報錯（指出第幾小節、和弦名、應為多少單位）。例（4/4、L:1/8）：
  
  - `G(4) d2u2d2u2` → 4拍=8單位，pattern 8 單位 ✓
    - `G(4) t1213121` → 8 單位 ✓
    - `G(4) dudu` → 4 單位 ≠ 8 → **錯誤**

- 和弦後沒有括號拍數：持續時間由 pattern 總長決定（`G d2u2d2u2` ＝ 8 單位）。

- 和弦後沒有 pattern：需要使用括號指定拍數，例如 `G(4)` 代表一次 `d` 刷全和弦、時值 4 拍。

- 弦上已發音的和弦在換和弦前持續（由時值表示，不需 sustain 事件）。

## 4. 弦編號映射（使用者習慣，1↔3 對調）

| 檔案寫 | 實際弦        |
| --- | ---------- |
| 1   | 3          |
| 2   | 2          |
| 3   | 1（最細，高音 e） |
| 4   | 4          |
| 5   | 5          |
| 6   | 6（最粗）      |

- 刷法事件指定到和弦圖標示的悶弦 `x` 時輸出 dead note；指法事件不套用此限制，未指定品位時使用空弦，強制品位會覆寫空弦。

## 5. 刷弦行為

- d/u 的所有音符**同時發音**；以 `TGStroke`（方向）標示上/下刷。時間微錯開不做，交由 TuxGuitar 處理。
- `t` ＝根音單音；`n` ＝單弦單音；`(ab…)` ＝同時多音。

## 6. 和弦字典（v1 範圍）

- 開放和弦：C, D, E, Em, Am, A, A7, D7, E7, G, G7, F（簡化版可用小封閉）、Cadd9, Dm, Asus4, Dsus4…
- 每筆資料：弦 1~6 的 fret（-1＝悶／不發音）、根音所在實際弦、發音弦清單。
- 封閉和弦規則：根音 + 主要三音推導（如 F#m = A 形移 2 格），v1 僅支援根音在 5/6 弦的自然推移變體（升／降半音的 major/minor/7）。
- 未識別的和弦名 → 錯誤（指出小節與名稱）。

## 7. 轉換到 TGSong

- 1 條 track、6 弦 standard tuning（E2 A2 D3 G3 B3 E4，實際弦 6→1 由粗到細）。
- 每個 pattern 事件 → 一個 `TGBeat`：
  - d/u → 和弦所有發音弦各一顆 `TGNote`（fret 來自和弦字典），`TGBeat` 掛 `TGStroke`。刷速 `~N` 指定時用對應的 TGStroke value；未指定時預設 16 分音符（並沿用先前指定的刷速）。
  - t → 根音弦一顆 note；n / (ab) → 對應弦 note。
  - z / - → 休止 beat（無 note）。
  - 連音群組 `[..]` 的事件 → 每個事件一個 `TGBeat`，時值 = 1 拍 / 事件數，並在 `TGDuration` 的 `TGDivisionType` 設定連音（3→3/2、5→5/4、6→6/4）。
  - 和弦出現的第一個 beat 掛 `TGChord`（和弦圖顯示）。
- `Q:` → `TGTempo`；`M:` → `TGTimeSignature`；`L:` 決定 1 單位 = `TGDuration`（1/8 → EIGHTH）。
- 小節 → `TGMeasure`/`TGMeasureHeader`，依拍號切分；弱起小節依實際單位數建 header。

## 8. 錯誤報告格式

`第 N 行、第 M 小節：描述`，例如：

```
SimpleInput: 第 3 行、第 2 小節：小節總時值 10 單位，超過 4/4 的 8 單位
SimpleInput: 第 5 行、第 1 小節：未識別的和弦「H7」
```

任何錯誤 → 匯入中止，不產生歌曲。

## 9. v1 明確不做

- `x` 悶音、@ 巢狀、刷弦時間微錯開、多 track、非 standard tuning、歌詞/力度標記。
